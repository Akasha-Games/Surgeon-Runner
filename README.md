# 📌 Project Overview

**Surgeon Runner** is a horror-inspired endless runner developed using **Unity Engine** and **C#**.

Players navigate through an abandoned hospital while avoiding dangerous medical obstacles, collecting syringes, and surviving for as long as possible to achieve the highest score.

This project serves as a comprehensive learning platform where I continuously explore modern game development concepts including:

- Gameplay Programming
- Mobile Game Development
- UI/UX Design
- Software Engineering
- Android Optimization
- Lighting & Rendering
- Animation Systems
- Scene Management
- Audio Systems
- Object-Oriented Programming
- Performance Optimization
- Version Control using Git & GitHub

Unlike a tutorial project, Surgeon Runner is being developed incrementally while documenting every milestone, challenge, optimization, and feature implementation.

The objective is not only to create a polished mobile game but also to strengthen professional software engineering practices used throughout commercial game development.

# 🏗️ Software Architecture

Surgeon Runner follows Unity's **Component-Based Architecture**, where each gameplay system is implemented as an independent module responsible for a specific task. This modular approach improves maintainability, scalability, and debugging while reducing coupling between systems.

Each gameplay feature is encapsulated inside its own C# script, allowing new mechanics to be added without affecting existing systems.

---

# 🧩 High-Level Architecture

```
                         Game Manager
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
        ▼                     ▼                     ▼
 Player Controller      UI Manager         Audio Manager
        │                     │                     │
        │                     │                     │
        ▼                     ▼                     ▼
 Movement System      Score System         Music Manager
        │                     │
        ▼                     ▼
Collision System     Save System
        │                     │
        ▼                     ▼
 Collectibles      High Score Manager
        │
        ▼
 Game Over Manager
```

The architecture was intentionally designed to separate gameplay logic, presentation, audio, and persistence into independent systems.
